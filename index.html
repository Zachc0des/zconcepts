# Z·Concepts — Zachary's Investing & Trading Concepts A slower, steadier perspective on easing your way into *potential* participation in financial markets — built on study, patience, and knowing when to step away. 🔗 **Live site:** [zachc0des.github.io/zconcepts](https://zachc0des.github.io/zconcepts/) > ⚠️ **Educational content only — not financial advice.** See the [Disclosures](#disclosures) section below and on the site. --- ## About Most market content pushes urgency — act now, don't miss out, get in early. **This site is the opposite.** It documents six years of following the markets (breaks included) and a framework for slowing the process down: observe first, simulate second, and only then consider whether real participation fits your life, your finances, and your temperament. Participation is potential, not required. ### Sections | Section | Description | |---------|-------------| | **Journey** | Six years of study — with intentional breaks visualized on a timeline. Rest is part of the process, not an interruption to it | | **Perspective** | The case for slowing down: observe → simulate → then decide | | **Concepts** | The five-part study framework (below) | | **Disclosures** | Risk warnings and disclaimers — read before anything else | ### The Study Framework | ID | Concept | Focus | |----|---------|-------| | ZC-01 / PA | **Price Action Review** | Reading raw market movement — structure, momentum, and behavior around key levels — before layering on indicators | | ZC-02 / BT | **Back Test Simulation** | Replaying historical data to pressure-test an idea before risking anything real. Simulation first, always | | ZC-03 / OB | **Order Book Analysis** | Studying bid/ask depth to understand where liquidity sits and how participants position themselves | | ZC-04 / MM | **Micro & Macro Analytics** | Zooming between individual setups and the big picture — rates, cycles, and global context | | ZC-05 / CT | **Miscellaneous Charting Techniques** | Timeframes, drawing tools, and visualization methods that clarify rather than clutter | --- ## Tech & Design - **Stack:** Single static HTML file — pure HTML / CSS / vanilla JavaScript, no frameworks, no build step - **Hosting:** GitHub Pages - **Typography:** Cormorant Garamond (display) + Share Tech Mono (labels/data) - **Theme:** Dark navy trading-terminal aesthetic with cobalt accents - **Signature touches:** - Scrolling "principles ticker" (patience ▲, FOMO ▼, journaling ▲, revenge trading ▼) - Decorative simulated candlestick chart drawn on canvas (random walk — no real data) - Study/break timeline visualization - `prefers-reduced-motion` support and responsive layout This site is part of the [Z.Frederic portfolio ecosystem](https://zachc0des.github.io) alongside [Zach/C0des](https://zachc0des.github.io/Zachc0des-Portfolio/#/) (study library), [Six Cards](https://zachc0des.github.io/sixcards/) (business card design), and [Z.JIM](https://zachc0des.github.io/zjim/) (training log). --- ## Running Locally No build tools needed: ```bash git clone https://github.com/Zachc0des/zconcepts.git cd zconcepts # open index.html in a browser, or serve it: python3 -m http.server 8000 ``` Then visit `http://localhost:8000`. --- ## Disclosures - **Not financial advice.** All content is for educational and informational purposes only.
