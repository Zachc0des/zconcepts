## Tech & Design

- **Stack:** Pure HTML / CSS / vanilla JavaScript — no frameworks, no build step
- **Hosting:** GitHub Pages
- **Typography:** Cormorant Garamond (display) + Share Tech Mono (body)
- **Signature touches:**
  - Live animated wave field (canvas) reacting to cursor position
  - SVG fractal-noise grain overlay
  - Scrolling skills ticker
  - Scroll-reveal animations via `IntersectionObserver`
  - Active nav highlighting on scroll
  - Full `prefers-reduced-motion` support and responsive layout

## Running Locally

No build tools needed — it's a single static file.

```bash
git clone https://github.com/Zachc0des/zachc0des.github.io.git
cd zachc0des.github.io
# open index.html in a browser, or serve it:
python3 -m http.server 8000
```

Then visit `http://localhost:8000`.
